The Grasshopper plugin can sign in and upload. The consent page shows built-in apps as such, lets someone in several organizations pick one, and mints through the server core rather than calling back into the app, which fixes approval behind a forward-auth proxy. `/team/tokens` shows to anyone who can create a definition, offering them an "Upload definitions" key, and `DELETE /api/v1/me/token` lets a key revoke itself.
