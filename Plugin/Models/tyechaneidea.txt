It doesn't exist in C# and doesn't make sense for number inputs:
export interface NumberWidgetConfig {
	min?: number;

	step?: number;
	renderAsSlider?: boolean;
}
3. Consider a Guid type alias (Optional, for clarity)

4. Add config to output layout items (Optional)
The C# LayoutItem always has a Config property. TypeScript output items don't have it, which could cause issues if you ever need output-specific config.
