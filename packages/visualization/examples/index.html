@selvajs/visualization — Examples

Start at the top and work down — the first demo is the whole library in 80 lines, the rest go deeper. Run with pnpm example (Vite transpiles the TypeScript imports; a static file server will not work).

1 · Getting Started

Read this one first. The smallest real app: initThree → getThreeObjectsFromComputeResponse → updateScene → dispose. No harness — the source is what you would paste into your own project.

2 · Display Items

What comes out of a real GH compute response: getThreeObjectsFromComputeResponse decoding the mesh blob plus curves and points, counted by kind.

3 · Outliner

An object-list panel over a live scene with createSceneOutliner: layer groups, search, hide/show, click and shift-range selection — and applyTo() keeping hidden state across a re-solve.

4 · Viewer — Full API

Every initThree control in one panel: 2D/3D and preset views, grid, nav cube, mesh edges, ambient occlusion, looks, lighting dials, and measurement.

5 · Mesh File — Selva Pipeline

A .slvm file through Selva's exact parse + updateScene calls, with the app's viewer options copied verbatim — for verifying the look 1:1 with production.
